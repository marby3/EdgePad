# Roadmap: EdgePad

Done means: Windows 10 21H2以降 / 11（x64）で、画面の上下左右の端にタッチ・マウスで押せるマクロキーパッドを出す常駐ソフトが、単体exe1本（1MiB以下）で動く。指で修飾キーを押さえたまま（またはラッチして）ペンで描くと、前面アプリ（CLIP STUDIO PAINT など）にはキーボード＋ペン操作として届く。キーは仕様書 4.2 の全種類（modifier / hold / shortcut / repeat / macro / text / run / page / pie）を持てる。キー配置はテキストの設定ファイル1つで決まり、前面アプリに応じて自動で切り替わる。設定ファイルの全項目は、トレイから開く本体内蔵の設定画面でも編集できる。高DPI・マルチモニタで正しく出て、半透明・テーマ・ドッキングなど仕様書 5 章の表示オプションを選べる。待機時CPU 0%、プライベートメモリ2.5MB以下を目標とし、押下中のキーはどの終了経路でも必ず解放される。CSP向けプリセットと説明書を同梱し、GitHubの公開リポジトリでリリースする。

仕様の正本は EdgePad 仕様書（2026-10-22）。各フェーズは仕様書のマイルストーン M0〜M4 におおむね対応する（高DPI・マルチモニタは実用に必須なので M3 から v0.2 へ前倒し。パイメニューは後から加えた v0.5、設定画面は v0.6 で、どちらも M3 と M4 の間に入る）。

## v0.1 - 技術検証: 左辺の固定5キーでCSPに指Ctrl＋ペン描画が効く（M0）
- chore: Cargoプロジェクト雛形。コア（OS非依存）とWindows層のモジュール分割、依存は windows-sys のみ、サイズ最適化のリリースプロファイル、GitHub Actions でビルド・テスト・exeサイズ確認
- feat: 左辺に固定5キー（Esc / Ctrl / Shift / Alt / Space）のパネルを表示する。NOACTIVATE / TOPMOST / TOOLWINDOW / LAYERED、GDI＋UpdateLayeredWindow で描画
- feat: WM_POINTER でタッチ・マウスを受け、押している間だけキーを押下する（ポインタIDごとの追跡、複数指の同時押し、キー外へ出ても離すまで維持、ペンは無視）
- feat: 最小のトレイアイコン（終了のみ）と、終了時・パニック時の全キー解放
- docs: 実測結果の記録（exeサイズ、メモリ、待機時CPU、CSPで指Ctrl＋ペン描画の可否）

## v0.2 - 最小実用版: 設定ファイルで4辺を組み、どのモニタ・DPIでも使える（M1＋M3の一部）
- feat: 設定ファイルパーサ（仕様書 7 章の文法すべて: [general] / [edge.*] / [set.*] / [profile.*]、キー名と組み合わせ、全キー種類、エラーの行番号と理由）。exe同フォルダ優先、なければ %APPDATA%\EdgePad。v0.2 では [profile.default] だけを使う
- feat: 4辺のパネルとレイアウト計算（辺ごとの有効/無効、列数・行数 1〜3、キー幅の倍率）
- feat: Per-Monitor DPI Aware V2 と WM_DPICHANGED での再レイアウト
- feat: マルチモニタ対応（辺ごとに primary / 番号 / cursor、WM_DISPLAYCHANGE で再計算）
- feat: shortcut キー（定義上の修飾キーとの合成、拡張キーとスキャンコード、独自 dwExtraInfo）。未実装のキー種類は押しても何も送らない
- feat: 設定の自動再読込（FindFirstChangeNotification＋MsgWaitForMultipleObjects）。読込エラー時は直前の設定で動き続ける
- feat: トレイメニュー（辺ごとの表示切替、設定ファイルを開く、再読込、一時停止、全キー解放、Windows起動時の自動起動、終了）、エラーのトレイ通知、多重起動防止（2回目の起動は表示切替）
- feat: グローバルホットキーで全辺の表示切替
- feat: ハンドルの表示と操作（内側へのスワイプで表示、端方向へのスワイプで非表示、タップで切替）
- feat: パネル非表示・セッションのロックとユーザー切替・スリープ移行で押下中のキーを解放する
- chore: CI で起動中のプライベートメモリを測り、2 MiB を超えたら落とす（v0.2 の途中で追加）
- feat: --debug 起動時のみ同フォルダへテキストログを出す

## v0.3 - キー機能とプロファイル: アプリごとに自動で切り替わるショートカットパッド（M2）
- feat: 修飾キーの状態機械（250ms未満のタップでラッチ、再タップで解除、長押しは押している間だけ、shortcut との合成後のワンショット解除／常時固定の設定）。ラッチ中のキーも既存の全解放経路の対象にする
- feat: repeat キー（押している間のオートリピート、間隔設定）
- feat: macro キーと text キー（待ち時間付きの順次送出、Unicode文字入力）
- feat: run キーと page キー（プログラム/URL起動、ページ送り、別キーセットへの切替）
- feat: アプリ別プロファイルの自動切替（SetWinEventHook、プロセス名照合、default、none、切替時の全キー解放）
- feat: トレイからプロファイルを一時固定する
- feat: 前面アプリが管理者権限で動いていてキーが届かない時にトレイ通知する

## v0.4 - 表示の仕上げ: 半透明・テーマ・ホバー・ドッキング（M3）
- feat: 半透明モード（短いスワイプで半透明、同方向スワイプで通常表示、半透明時もペンは無視）。v0.6 で、パイメニュー表示中とペンが乗っている時だけの自動の半透明に改めた
- feat: テーマ（ライト / ダーク / auto、アクセント色）
- feat: マウスの端ホバーで表示、最後の操作から一定時間で自動非表示（どちらも任意設定、既定オフ。ポーリングせずハンドルのマウスイベントとワンショットタイマーで実装）
- feat: ドッキングモード（SHAppBarMessage で辺をAppBar登録、任意設定）
- feat: 表示/非表示のスライドアニメーション（任意、既定オフ）

## v0.5 - パイメニュー: キーを押したまま方向へ滑らせて項目を選ぶ（仕様書 4.6、M3 の後に追加）
- feat: pie キーの設定（`key = ラベル | pie | キーセット名`、項目は参照先キーセットの先頭から2〜8個、使えない種類や項目数の誤りは行番号付きの読込エラー）
- feat: 方向から項目を選ぶ判定をコアに置く（押した位置からの移動量、中央の取消範囲、端の側への移動は取消。OSなしで単体テスト）
- feat: パイメニューの表示（押した位置を中心に画面の内側へ開く扇形、NOACTIVATE / TOPMOST / TOOLWINDOW / LAYERED、選択中の項目を強調、開いている間だけ窓とDIBを持つ）
- feat: 操作（押したまま滑らせて離すと実行、タップで開いたまま項目をタップ、ラッチ中の修飾キーとの合成とワンショット解除、パイキーを押している指は端へのフリックで隠さない、ペンは無視）
- feat: パネル非表示・プロファイル切替・画面ロック・スリープ・終了でパイメニューを閉じる

## v0.6 - 設定画面: 設定ファイルの全項目をトレイから開く画面で編集する（M3 の後に追加）
- chore: 設定画面を本体に内蔵する方針で目標を見直す（仕様書 7・8・9 章、exe サイズの上限を 500KiB から 1MiB へ、CI の上限も合わせる。メモリとワーキングセットの目標は設定画面を閉じている時の値として据え置く）
- feat: 設定の書き戻しをコアに置く（読み込んだ設定を変更して INI テキストへ戻す。変更していない行・コメント・並び順は元のまま、書き出したテキストはパーサで読み直して同じ設定になる。OSなしで単体テスト）
- feat: 設定画面の骨組み（トレイメニューの「設定…」で開く通常のウィンドウ、一般 / 辺 / キーセット / プロファイルのタブ、Per-Monitor DPI とテーマに追従、二重には開かない。保存はパーサで検証してから書き込み、反映は既存の自動再読込に任せる。開いている間に外でファイルが変わったら知らせて読み直すか選ばせる。窓と資源は開いている間だけ持ち、閉じたら待機時のメモリに戻る）。タブは次の作り直しでサイドバーに替える
- feat: 一般タブと辺タブ（[general] と [edge.*] の全項目。範囲外の値は入力欄で止める）。次の作り直しで画面から外し、辺と表示・操作の画面で入れ直す
- feat: 設定画面を OS 標準の部品とサイドバーで作り直す（キー配置 / アプリ別 / 辺と表示 / 操作の4画面、下端にファイルの場所・テキストで開く・保存の行、未保存の「●」と Ctrl+S、ライト / ダークは OS に従う。プライベートメモリの目標を一度も開いていない時・開いている間・閉じた後に分け、CI で毎回測る）
- feat: 半透明表示の見直し（既定は不透明、パイメニュー表示中とペンが乗っている時だけ自動で半透明、短いスワイプの半透明は廃止）
- feat: 設定画面を別のプロセスで開く（同じ exe の2つ目のプロセス、閉じたらメモリをすべて返す、常駐側は IME を使わない。常駐側の閉じた後のメモリの目標を 3MiB に戻す）
- feat: 辺と表示・操作の画面（[general] と [edge.*] の全項目、範囲外の値は欄で止める、画面の4辺の図で辺を選ぶ、ホイールと矢印での増減、保存エラーから誤りの欄へ移る）
- feat: キー配置画面（キーセットとキーの編集、パネルの見本、送るキーを一覧から選ぶ・押して取り込む、pie の項目にするキーセットを選ぶ）
- feat: アプリ別画面（プロファイルの追加・削除、開いているアプリから選ぶ、画面の図で辺ごとのキーセットを選ぶ）
- chore: 設定画面を入れた後の実測（exe サイズ、設定画面を開いている間と閉じた後のプライベートメモリ・ワーキングセット）を記録する

## v1.0 - 配布: CSPプリセットと説明書を同梱してGitHubリリース（M4）
- feat: 既定設定ファイルの同梱（設定がない時にCSP向けプリセットを書き出す）
- docs: README と設定リファレンス（設定画面の使い方、キー種類、キー名一覧、管理者権限の制約、F13〜F24の運用、動作確認した環境）
- chore: 出荷ビルドでの実測（待機時CPU、プライベートメモリ、ワーキングセット、起動時間、exeサイズ）と記録。目標未達なら別Issueで対処
- chore: ライセンス追加と、タグで exe・README・プリセット設定をまとめた zip を GitHub Release に添付する Actions

## Notes

- テストの方針: 設定パーサ、修飾キー状態機械、レイアウト計算、ジェスチャ判定、設定の書き戻しはコアに置き、OSなしで単体テストする。Win32層は SendInput の送出列を記録できる薄い抽象を挟み、送出順序をテストする。タッチ・ペン・CSPでの実機確認は各PRの報告に手順を書き、実機で見てもらう。
- 動作確認は手元の Windows 11 で行う。Windows 10 21H2 は使う API（WM_POINTER、Per-Monitor DPI V2 など）がすべて揃う下限として仕様に掲げるが、実機確認はしない。README にその旨を書く。
- 将来（このロードマップの範囲外）: macOS版、Linux（X11）版、キーのアイコン表示、ARM64版。
