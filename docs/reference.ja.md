# 設定リファレンス

[English](reference.md) | 日本語

EdgePad の設定ファイル `edgepad.ini` に書ける項目の一覧です。設定画面（トレイの「設定…」）でも、すべての項目を編集できます。

## ファイルの場所と書き方

- exe と同じフォルダの `edgepad.ini` を先に読みます（ポータブル動作）。なければ `%APPDATA%\EdgePad\edgepad.ini` を読みます。
- 文字コードは UTF-8 です。`[セクション]` のあとに `名前 = 値` を 1 行ずつ書きます。
- 行頭か、空白のあとの `;` から行末まではコメントです。
- 保存すると、EdgePad がすぐに読み直します。読めない所があれば、直前の設定のまま動き続け、行番号と理由をトレイの通知で知らせます。
- 数値の「0 でオフ」とある項目は、0 を書くとその働きを止めます。

## [general] 全体の設定

| 項目 | 意味 | 既定値 | 書ける値 |
|---|---|---|---|
| `hotkey` | 全辺の表示を切り替えるホットキー | `none` | `Ctrl+Alt+E` のようなキーの組み合わせか `none` |
| `key_size` | キー 1 つの大きさ（論理ピクセル） | `56` | 24〜200 |
| `opacity` | ふだんの不透明度（%） | `100` | 10〜100 |
| `dim_opacity` | パイメニューを開いている間と、ペンが乗っている間の不透明度（%） | `35` | 10〜100 |
| `latch_ms` | これより短いタップで修飾キーがラッチする（ミリ秒） | `250` | 50〜2000 |
| `latch` | ラッチの解け方 | `oneshot` | `oneshot`（1 回使うと解ける）/ `lock`（もう一度押すまで続く） |
| `pen_presses` | ペンでキーを押せるか | `false` | `true` / `false` |
| `theme` | パネルの色 | `auto` | `light` / `dark` / `auto`（Windows に合わせる） |
| `accent` | 押したキーの色 | `auto` | `auto`（Windows のアクセント色）か `#RRGGBB` |
| `hover_ms` | マウスをハンドルに乗せてからパネルを出すまで（ミリ秒） | `0` | 100〜5000、0 でオフ |
| `auto_hide_ms` | 最後の操作から自動で隠すまで（ミリ秒） | `0` | 1000〜3600000、0 でオフ |
| `slide_ms` | パネルが出入りする時間（ミリ秒） | `0` | 50〜500、0 でオフ |

## [edge] と [edge.left] [edge.right] [edge.top] [edge.bottom] 辺の設定

`[edge]` に書いた項目は全部の辺に効き、`[edge.left]` などに書いた項目は、その辺だけで `[edge]` より優先します。

| 項目 | 意味 | 既定値 | 書ける値 |
|---|---|---|---|
| `enabled` | その辺を使うか | `true` | `true` / `false` |
| `dock` | パネルの厚みだけ画面の端を空け、最大化した窓がパネルの下に入らないようにする | `false` | `true` / `false` |
| `gap` | パネルとハンドルを画面の端から離す距離（論理ピクセル） | 下の辺は `16`、ほかは `0` | 0〜64 |
| `start` | 起動した時と読み直した時に、その辺を出しておくか隠しておくか | `shown` | `shown` / `hidden` |
| `monitor` | パネルを出すモニター | `primary` | `primary` / `1`〜`16` / `cursor`（パネルを出す時にマウスのあるモニター） |
| `columns` | 左右の辺の列数 | `1` | 1〜3 |
| `rows` | 上下の辺の行数 | `1` | 1〜3 |
| `handle` | パネルを隠している時に残す帯（ハンドル）。幅（ピクセル）、長さ（%）、位置（%） | `6, 40%, 50%` | `幅, 長さ%[, 位置%]`（幅 4〜8、長さ 1〜100、位置 0〜100）か `none` |

## [set.名前] キーセット

キーを並べたものです。名前には英数字と `-` `_` が使えます。

| 項目 | 意味 |
|---|---|
| `key` | キー 1 つ。`key = ラベル \| 種類 \| 内容 \| オプション` の形で、並べたい順に何行でも書く |
| `layout` | 並べ方。書かなければ辺に沿って並べる。`free` は自由配列、`kle:ファイル名` は Keyboard Layout Editor の配列 |

### キーの種類

| 種類 | 働き | 内容の例 |
|---|---|---|
| `modifier` | 押している間だけ押す。短くタップするとラッチ | `Ctrl` / `Shift` / `Alt` / `Win` |
| `hold` | 押している間だけ押す。ラッチしない | `Space` |
| `shortcut` | 離した時に 1 回送る。ラッチした修飾キーと合わせて送る | `Ctrl+Z` |
| `repeat` | 押している間くり返し送る | `[` |
| `macro` | キー操作を順に送る。`wait ミリ秒` で待つ | `Ctrl+S, wait 300, Esc` |
| `text` | 文字列をそのまま入力する | `よろしくお願いします` |
| `run` | プログラムやファイル、URL を開く | `calc.exe` |
| `page` | パネルのページを替える | `next` / `prev` / キーセットの名前 |
| `pie` | パイメニューを開く。項目は内容に書いたキーセットのキー（2〜8 個） | キーセットの名前 |
| `layer` | パネルを別のキーセットに切り替える | キーセットの名前 |
| `none` | 何も送らない | `-` |

### キーのオプション

| オプション | 使える種類 | 意味 | 書ける値 |
|---|---|---|---|
| `width` | 辺に沿って並べる時 | キーの幅（キーいくつ分か） | 1〜3 |
| `interval` | `repeat` | くり返しの間隔（ミリ秒） | 20〜1000（既定 50） |
| `mode` | `layer` | `hold` は押している間だけ、`toggle` は押すたびに切り替える | `hold` / `toggle` |
| `x` `y` | `layout = free` | キーの位置（キーいくつ分か、0.25 刻み） | 0〜40 |
| `w` `h` | `layout = free` | キーの幅と高さ（キーいくつ分か、0.25 刻み） | 0.25〜8（既定 1） |

`layout = kle:ファイル名` のキーセットでは、位置は KLE のファイルから読みます。キーは上の行から順に（同じ高さなら左から）key 行に 1 つずつ割り当てます。回転したキーも、KLE と同じ角度で出します。

## [profile.名前] プロファイル

前面のアプリに合わせて、辺ごとのキーセットを切り替えます。どのプロファイルにも当たらない時は `[profile.default]` を使います。

| 項目 | 意味 |
|---|---|
| `process` | このプロファイルを使うアプリの実行ファイル名（例: `CLIPStudioPaint.exe`）。`default` には書かない |
| `left` `right` `top` `bottom` | その辺に出すキーセットの名前。`none` はその辺を出さない |

## キー名

キーの組み合わせは `+` でつなぎます（例: `Ctrl+Shift+S`）。大文字と小文字は区別しません。

| キー名 | キー |
|---|---|
| `A`〜`Z`、`0`〜`9` | 文字と数字のキー |
| `F1`〜`F24` | ファンクションキー |
| `Ctrl` `Shift` `Alt` `Win` | 修飾キー |
| `Space` `Enter` `Esc` `Tab` `Backspace` `Delete` `Insert` | |
| `Home` `End` `PgUp` `PgDn` | |
| `Left` `Right` `Up` `Down` | 矢印 |
| `` ` `` `-` `=` `[` `]` `\` `;` `'` `.` `/` | 記号（US 配列の位置のキー） |
| `Comma` | `,`（マクロの区切りと区別するため名前で書く） |
| `Numpad0`〜`Numpad9`、`Multiply` `Add` `Subtract` `Decimal` `Divide` | テンキー |
| `Hankaku` `Henkan` `Muhenkan` `Kana` `Ro` | JIS 配列だけのキー（半角/全角、変換、無変換、カタカナひらがな、ろ） |

JIS 配列のほかのキーは、Windows が同じキーとして送る US 配列のキーの名前で書きます（`@` は `` ` ``、`¥` は `\`、`^` は `'`、`;` は `=`、`:` は `;`）。
